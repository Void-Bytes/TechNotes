# Useful Commands
## clone
Clones a remote repository.
A directory with the name of the repository is created in the current directory.
```
git clone https://github.com/Void-Bytes/TechNotes
```
## pull
Fetches and pulls new commits from the remote repository into the local branch.
```
git pull
```
## ls-tree
Lists files registered in the repository
```
git ls-tree -r master --name-only
```
